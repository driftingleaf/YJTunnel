# 管理台手册

浏览器访问 `http://<服务器IP>:5103`（账号密码见 `tunnelserver.json`，来源受 `Admin.AllowedIps` 白名单约束——留空 = 仅本机回环可访问）。

> 安全提醒：管理台端口 5103 切勿对公网放行；白名单配置为 `["*"]` 时任意来源均可访问，密码是唯一屏障。

## 页面总览

### 总览

在线客户数、已分配端口数、待审核数量、绑定失败告警；在线会话表每 5 秒自动刷新（可暂停）。

### 客户管理

- 列表：客户名、ClientId、机器名/版本、最后登录、端口映射、在线状态
- 新增/编辑：ClientId（客户端生成）、名称、备注、启用状态
- 操作：编辑、踢下线（客户端自动重连）、删除（端口分配记录一并删除，客户端将无法登录）

客户名支持自动记录：客户端登录时上报其配置的公司名称，建档与待审核直接显示；管理台手工命名的档案不会被客户端覆盖。

### 端口分配表

- 每行 = 一个已分配的远端端口：端口 / 客户 / 本地端口(key) / 绑定状态
- 状态语义：

| 状态 | 含义 |
|---|---|
| ● 在线已绑定 | 正常工作 |
| ● 绑定失败（被他人持有） | 端口被其他客户的监听持有（冲突，需换端口） |
| ◌ 未绑定 · 等待客户端重连 | 客户在线但该端口尚未绑定（重连窗口/绑定失败待重试） |
| ○ 离线 | 客户端不在线 |

- **改端口**：高危操作（会导致该客户所有远程客户端配置的地址失效，需逐台修改）。保存前服务端会前置校验（白名单/黑名单/跨客户唯一/同客户映射唯一/本机占用），不通过直接报错不保存；保存成功后在线客户端秒级收到变更通知，自动重连绑定新端口，页面自动刷新（30 秒未成功则停止轮询）
- 支持 CSV 导出（UTF-8 BOM，Excel 直开）

### 待审核

服务端 `AutoRegister=false` 时，持有合法 Token 的未知客户端首次登录会进入待审核队列（显示公司名/机器名/申请映射）。通过 = 自动建档 + 分配端口，客户端稍后自动上线；拒绝 = 该客户端后续登录直接拒绝。

### 操作日志

`logs/events.jsonl` 的时间线视图：登录/注销/端口分配/管理操作/绑定失败/心跳收割等。保留 90 天。按客户/类型筛选。

## 常用运维操作

| 场景 | 操作 |
|---|---|
| 客户隧道不通 | 总览看在线状态 → 不在线查客户端错误提示；在线但端口不通 → 端口表看绑定状态 |
| 客户重装系统（ClientId 变化） | AutoRegister=true 时会新建档（旧档成孤儿记录可删除），端口可被新会话接管 |
| 需要临时断开某客户 | 客户管理 → 禁用（登录直接拒绝）或踢下线（会自动重连） |
| 改端口 | 端口分配表 → 改端口 → 确认高危提示 → 输入新端口 → 保存自动推送生效 |
